# Архитектура

```
  микрофон / текст
        |
        v
  brain (Python)
    персона PERSONA.md
    ложные воспоминания: lore/*.md → поиск → промпт
    LLM: локально Ollama или API
    tool-calling
        |
        +--> TTS --> динамик в груди
        |
        v
     ESP32  (исполнитель тела)
        глаза WS2812 | сигара | челюсть | люк | руки позже
        |
  3D-печатный корпус, металлик
```

## Кто что делает

| Узел | Задача |
|---|---|
| **LLM + brain** | Я Бендер. Память из файлов. Решает, какой tool. Живёт дважды: `brain/` (Python, железо) и `lib/` (Node, морда и бот) — память у обоих одна. |
| **TTS** | Голос в комнату (пока — speechSynthesis планшета). |
| **`app.js` + планшет** | Витрина и морда: лендинг, Telegram-бот, очередь `/api/face`; глаза и рот — на экране iPad. `/ask` отвечает из памяти, `/voice` настраивает голос. |
| **ESP32** | Только железо, без характера. |
| **3D-принтер** | Корпус. |
| **Мини-ПК / Pi 5** | Где крутится brain. При 500к можно не мучить 7B на слабом Pi, а взять мини-ПК 32GB. Pi остаётся запасным. |

Arduino Uno — не мозг и не ИИ.

## Голова — планшет (раунд 5)

Голова — **iPad в напечатанном корпусе**: **глаза и рот живут на экране планшета** — и это
рабочий вариант, а не заглушка. Экран вставляется в голову — она оживает: `public/index.html`
моргает, следит, говорит голосом планшета (speechSynthesis), рот синхронизирован с озвучкой.
Печатный рот с серво — опция на потом, если захочется дублировать железом (см. `NEXT_ROUND.md`).

```
Telegram (хозяин)                     планшет в голове
  /say текст ─┐                      ┌─ глаза: SVG, моргание, взгляд
  /expr happy ─┴─► app.js: бот ─► очередь команд ─► GET /api/face?since=N (раз в 2 c)
                                                      └─► say: говорит вслух; expr: выражение
```

- Лендинг, морда и бот — один процесс `app.js` (деплой на BotHost), ноль зависимостей
  (jsdom и resvg — только для тестов и скриншотов, в прод не едут).
- Переменных для хозяина всего две: `BOT_TOKEN` и `ADMIN_ID` (кто имеет право сказать через морду).
- Морда сама ходит на сервер — планшет может висеть в любой сети, серверу не нужно искать iPad.
- Тело вокруг головы собирается физически: ESP32, серво (люк, челюсть-опция), сигара.

## Два слоя «я»

1. **Канон** — ложные воспоминания сериала: ядро в `brain/PERSONA.md`, всё остальное в `brain/lore/`.
2. **Шасси** — это напечатанное тело и честный список `brain/TOOLS.md`.

Путаница слоёв = робот, который « ascends на корабль» не вставая со стола. Нельзя.

## Рантайм-мозг (раунд 3, без железа)

`brain/` — Python-пакет, стандартная библиотека и ничего больше:

| Модуль | Роль |
|---|---|
| `persona.py` | `PERSONA.md` + всплывшая память → системный промпт + правила тела |
| `lore.py` | долговременная память: `lore/*.md` → куски по `##`/`###` → BM25 (раунд 4) |
| `tools.py` | каталог инструментов (схемы из `TOOLS.md`), валидация, сухой исполнитель |
| `llm.py` | заглушка на правилах и шаблонах + слот под Ollama |
| `runtime.py` | склейка: реплика → персона → LLM → tools → ответ |
| `cli.py`, `__main__.py` | `python -m brain`: диалог или одна реплика |

Порядок тела: сначала действия (глаза, сигара, люк), потом речь — `say` зовётся в конце.
Пока нет железа каждый tool пишет в `var/dry_run.log` и возвращает `dry_run: true`.
Инструмента нет в каталоге — вызов отклоняется: модель не выдумывает конечности.

## Мозг и память на Node (раунд 5+)

```
Telegram /ask ──► lib/brain.js ──► lib/lore.js ──► brain/lore/*.md   (BM25, 267 кусков)
                      │                               ▲
                      │                               └── те же файлы читает brain/lore.py
                      ├── LLM_URL задан? ──► живая модель (Ollama / OpenAI-совместимый)
                      └── нет ──► заглушка на правилах (порт brain/llm.py:StubLLM)
                                          │
                                          └──► очередь /api/face ──► планшет говорит вслух
```

- `lib/lore.js` — порт `brain/lore.py` один в один: тот же стеммер, тот же BM25, те же пороги.
  Тесты сверяют верхушку выдачи с python-версией по контрольным запросам.
- `lib/brain.js` — персона + память + движок: `/ask` отвечает из канона, «не помню» вместо выдумок.
  Слот под модель включается переменной `LLM_URL`, путь проверен mock-сервером в `tests/brain.test.js`.
- Голос: `/voice bass|bender|fast|pitch=… rate=…` хозяин задаёт из Telegram, морда забирает
  настройку вместе с командами (`/api/face → voice`) и говорит своим `speechSynthesis`.
- Записанный голос: `public/audio/` + `manifest.json` — коронные фразы звучат файлами
  (запись по точному тексту), остальное — синтез планшета. Тест стережёт, что манифест
  и `QUOTES` не разошлись.
- Скриншоты: `npm run shots` (jsdom запускает настоящие `public/*.js`, resvg рисует PNG) → `docs/shots/`.

## Долговременная память (раунд 4)

```
реплика ──> lore.recall(k=3) ──> «## Всплыло в памяти (канон)» в системном промпте ──> LLM
              │
              └─ lore/*.md: 00 досье · 01 экипаж · 02 каст · 03 мир · 04 хронология
                            10–17 все серии (S01–S11, F1–F4) · 90 фразы
```

- Куски — заголовки `##`/`###` с контекстом родителя; строка `Ключи:` — синонимы для поиска.
- Токены: нижний регистр, ё→е, стоп-слова, грубый стеммер (русский + английский), основа ≥ 3 букв.
- BM25 (k1 = 1.5, b = 0.75), заголовок ×3, ключи ×2, бонусы за слово запроса в заголовке и за
  героя, названного целиком. Порог шума `MIN_SCORE`, порог «уверен без слова помнишь» `STRONG_SCORE`.
- Вспоминать — **не** инструмент тела: каталог `TOOLS.md` не меняется, памяти не нужен dry-run.
- Заглушка: вопрос о прошлом («помнишь», «расскажи про», «кто такой», «серия»…) → первые
  1–2 предложения верхнего куска в характере; про серию — берёт кусок-серию; пусто → «не помню».
- Ollama получает те же куски в промпте плюс правило «нет в памяти — не выдумывай».
- `python -m brain --recall ЗАПРОС` — отладка памяти; `--no-lore` — амнезия.

## Масштаб тела

С 500к цель всё ещё **убедительный прототип голова+торс (+руки-зачатки)**, не ростовой боевой мех.
ИИ не требует двухметрового корпуса. Характер живёт в промпте и tools.

Подробности характера и tools: `brain/PERSONA.md`, `brain/TOOLS.md`.
