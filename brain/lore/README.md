# Лор: долговременная память Бендера

Всё в этой папке (кроме этого README) — **воспоминания Бендера от первого лица**.
`brain/lore.py` режет файлы на куски по заголовкам `##`/`###`, ищет BM25 и
на каждом ходе подкладывает в системный промпт 1–3 самых подходящих куска
(«Всплыло в памяти»). Отдельного инструмента нет: вспоминать — не действие тела.

| Файл | Что внутри |
|---|---|
| `00_bender.md` | досье на себя: паспорт, происхождение, тело, привычки, семья, романы |
| `01_crew.md` | экипаж «Межпланетного экспресса» и корабль |
| `02_cast.md` | все остальные: Запп, Мамочка, Калькулон, Робот-Дьявол, Флексо… |
| `03_world.md` | мир 3000-х: Нью-Нью-Йорк, кабинки, головы, роботы, DOOP, планеты |
| `04_timeline.md` | хронология: показ в нашем мире и события внутри сериала |
| `10_s01.md` … `13_s04.md` | сезоны 1–4 (Fox), по серии на заголовок |
| `14_films.md` | четыре фильма (= сезон 5, S05E01–E16) |
| `15_s06.md`, `16_s07.md` | сезоны 6–7 (Comedy Central) |
| `17_hulu.md` | сезоны 8–11 (Hulu, у Hulu это 11–14) |
| `90_quotes.md` | коронные фразы — мои и чужие |

## Правила записи

- Заголовок серии: `### S04E07 · Jurassic Bark` (фильмы — `### F1 · …`).
  Нумерация — **производственные** сезоны, как в `04_timeline.md`.
- Первые 1–2 предложения — суть: заглушка цитирует именно их.
- Строка `Ключи:` — синонимы и русские имена для поиска (вес ×2).
- Не уверен — пиши «подробностей не помню». **Не выдумывай сюжетов**:
  лучше дыра в памяти, чем ложная память, которую не заказывали.
