# Инструменты: рот → физический Бендер

Мозг (LLM) не дёргает GPIO. Мозг вызывает **tool**. `brain` исполняет. ESP32 шевелит железо.

```
человек → микрофон/чат
        → LLM (персона + память + список tools)
        → tool call JSON
        → brain/runtime
        → ESP32 / TTS / камера
        → результат tool обратно в LLM
        → речь в динамик
```

## Контракт

Каждый tool: имя, аргументы, **что происходит с телом**, что вернуть модели.

Пока железа нет — runtime пишет в лог `dry-run`. Модель всё равно учится звать tools, не врать, что «уже подмигнул».

## Каталог v0 (обещанные телу)

| Tool | Аргументы | Тело | Когда нет железа |
|---|---|---|---|
| `say` | `text` | TTS в динамик, челюсть в такт если есть серво | только лог + файл wav позже |
| `eyes` | `mode`: on/off/dim/angry/party | WS2812 | лог |
| `cigar` | `on`: bool | красный LED | лог |
| `chest` | `open`: bool | серво люка | лог |
| `jaw` | `pos` 0–100 | серво рта | лог |
| `antenna_bob` | — | серво/LED антенны если будет | лог |
| `wave` | `side`: left/right/both | руки, когда появятся | «рук нет, старина» |
| `look` | — | кадр с камеры, описание | нет камеры → ошибка tool |
| `status` | — | питание, серво, ping ESP | json |

Модель **обязана** звать `say` для речи в комнату. Текст в чат без `say` — только отладка с ноутбука.

Запрещённые tools навсегда: управление чужими замками, атака сетей, покупки с карты без явной команды мясомешка отдельным раундом.

## Формат вызова (черновик)

```json
{
  "tool": "eyes",
  "args": { "mode": "angry" }
}
```

Ответ железа:

```json
{
  "ok": true,
  "tool": "eyes",
  "result": { "mode": "angry" },
  "dry_run": true
}
```

`dry_run: true` пока ESP32 не в сети. Персона не должна рассказывать, что «глаза вспыхнули», если `ok` ложь.

## Железо под tools (напоминание кассе)

Без ESP32 + LED `eyes`/`cigar` — театр.
Без динамика `say` — чат на экране, не робот.
Камера и руки — не блокер личности. Сначала рот, глаза, сигара, люк.
