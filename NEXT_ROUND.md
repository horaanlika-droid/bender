# Задание на раунд 3 (себе / агенту)

Касса: **500 000 ₽**, расход 0. Железо не покупать в этом раунде.

## Задача (одна)

Собрать **рантайм-мозг без железа**: Python-пакет `brain/`

- загрузка `PERSONA.md` в системный промпт;
- каталог tools из `TOOLS.md` / JSON-схемы;
- dry-run: вызов `eyes` / `cigar` / `say` пишет в лог и возвращает `{ok, dry_run: true}`;
- REPL или простой CLI: мясомешок пишет текст → ответ в характере Бендера + tool calls;
- без обязательного платного API: заглушка LLM (правила/шаблон), плюс слот под Ollama позже.

## Не делать

- CAD головы (это отдельный раунд).
- Закупки.
- Прошивку ESP32.
- Подключение карты / облака «на проде».

## Критерий

`python -m brain` (или скрипт в `brain/`) переживает диалог: «подмигни» → tool `eyes`, не рассказ «я подмигнул» без вызова.
