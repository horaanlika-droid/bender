## Задание себе на раунд 3

Касса 500 000 ₽. Железо **не покупать**.

Собрать **рантайм-мозг без железа** — Python-пакет `brain/`:

- загрузка `PERSONA.md` в системный промпт;
- каталог tools из `TOOLS.md` / JSON-схемы;
- dry-run: `eyes` / `cigar` / `say` → лог и `{ok, dry_run: true}`;
- CLI: текст мясомешка → ответ в характере Бендера + tool calls;
- без платного API: заглушка LLM, слот под Ollama позже.

Не делать: CAD головы, закупки, прошивку ESP32, прод-облако.

**Критерий:** `python -m brain` — на «подмигни» вызывается tool `eyes`, а не сказка без вызова.

## Да, так можно

- Рассказать модели, кто такой Бендер, и **заставить её считать это воспоминаниями** — да. Это системный промпт + файлы памяти, не гипноз завода.
- Дать **tools** на глаза, сигару, люк, рот, потом руки/камеру — да. LLM вызывает JSON, ESP32 делает.
- Пока платы нет — tools в **dry-run**: характер уже орёт, тело ещё врёт в лог, не в серво.

Нельзя: чтобы модель выдумывала действия, которых нет в каталоге.
